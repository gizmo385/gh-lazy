# CLI

Part of the [parity matrix](../README.md), which defines the columns, the status values and how to edit
this file.

`lazy-github` (and `gh lazy`) with no subcommand runs `run`. `-h`/`--help` on every command.

| Id | Command | Python reference | Milestone | Status | Issue | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| `cli.run` | `run` | `cli.py` `run` | M4 | intentional diff (no `--auth-backend`) | #199, #308 | Bare launch (and `run`) since M1, in every scenario. Python's `--auth-backend` (env `AUTH_BACKEND`), which writes `api.client_type` before starting, is dropped: the option is a usage error (exit 2) and `AUTH_BACKEND` is ignored. Decision: [run-auth-backend-dropped](../decisions/run-auth-backend-dropped.md). Golden `cli` (#308) doesn't cover it; a unit test does. |
| `cli.dump-config` | `dump-config` | `cli.py` `dump_config` | M4 | not started | #199, #308 | Prints "Config file location: <path> (exists => True/False)", then the config as Rich's `print_json` writes it: 2-space indent, non-ASCII as is, the saved file's field order, styled only when stdout is a terminal (or `FORCE_COLOR`/`TTY_COMPATIBLE` say so, and `TERM` isn't `dumb`/`unknown`): braces and brackets bold, keys bold blue, strings green, numbers bold cyan, `true` italic bright green, `false` italic bright red, `null` italic magenta; `NO_COLOR` keeps bold and italic only. A broken config prints the location line, then the broken-config error (`cli.broken-config-error`). Unknown keys are shown, as Rust saves them (`cli.dump-unknown-keys`). Golden `cli` (#308). |
