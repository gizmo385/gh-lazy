# B1: Settings field ids aren't section-qualified

- Id: B1
- Status: open
- Python reference: `ui/screens/settings.py` `_id_for_field_input`, `_update_settings`
- Recommendation: Fix in Rust (`intentional diff`).
- Rows: `modals.settings-tabs`
