# B2: Settings saves numbers and null as strings

- Id: B2
- Status: open
- Python reference: `ui/screens/settings.py` `_update_settings`
- Recommendation: Rust saves typed values; the loader accepts numeric strings and treats `"None"` as null.
- Rows: `infrastructure.config-load-save`, `modals.settings-tabs`, `config.cache-auth-last-checked`

Settings stores text-input values as strings: numeric fields are saved as `"600"`, and a null `auth_last_checked` becomes `"None"` (which fails to load).

Raised for Chris in [this comment on #71](https://github.com/gizmo385/gh-lazy/issues/71#issuecomment-6392375110).
Until he answers, the recommendation stands and the specs for the rows above follow it.
