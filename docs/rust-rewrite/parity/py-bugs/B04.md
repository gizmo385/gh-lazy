# B4: Workflow runs keyed by the per-workflow run number

- Id: B4
- Status: open
- Python reference: `ui/widgets/workflows.py`
- Recommendation: Key by run id; keep the "Run #" column.
- Rows: `workflows.columns`

Workflow runs are keyed by `run_number`, which is per workflow, so runs of different workflows overwrite each other.

Raised for Chris in [this comment on #71](https://github.com/gizmo385/gh-lazy/issues/71#issuecomment-6392375110).
Until he answers, the recommendation stands and the specs for the rows above follow it.
