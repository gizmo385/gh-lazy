# B31: Sections hidden by config still take focus

- Id: B31
- Status: open
- Python reference: `ui/screens/primary.py` `SelectionsPane.compose`, `MainViewPane.action_focus_section`, `action_focus_workflow_tabs`
- Recommendation: Keep Python's behavior for parity: `2`/`3`/`4` focus a section hidden by config.
- Rows: `main-layout.focus-switching`, `main-layout.focus-ring`

`SelectionsPane.compose` hides the PR, issues and workflows sections with `display = False` only, so `visible` stays
true and `action_focus_section`'s `if target.visible` check passes. Pressing `2` (or `3`, `4`) with that section hidden
by `appearance.show_*` focuses its off-screen table: no box shows a focused border, and the footer lists the hidden
section's bindings (`/ Search  O Lookup Pull Request  E Edit PR  u View User …`). Tab then goes to the repos table,
because the hidden table isn't in the focus chain. Runtime toggles (`action_toggle_ui`, M4) set both `display` and
`visible`, so `2`/`3` do nothing for a toggled section; `4` never checks.

Found while specifying #75; see [the comment on #75](https://github.com/gizmo385/gh-lazy/issues/75).
Until Chris answers, the recommendation stands and the specs for the rows above follow it.
