# B38: A rebound binding stops working while a text input has focus

- Id: B38
- Status: answered
- Answer: Filter by the effective keys, after overrides apply, not by the default keys. (Chris, 2026-10-25, in a Claude Code session; see #169)
- Python reference: Textual 8.2.5 `Screen._binding_chain` (the "Filter out bindings that could be captured by widgets" loop, then `apply_keymap`), `Input.check_consume_key`; `ui/widgets/common.py` `ToggleableSearchInput`
- Recommendation: Keep Python's behavior: filter outer bindings by their default keys, before overrides apply. It changes nothing with the default keymap, and it keeps the footer showing only keys that work in the box.
- Rows: `searchable-tables.search-box-key-filter`

While an `Input` (the table search box) has focus, Textual removes from every outer link of the binding chain each key
the input would consume, which is any key with a printable character. It does this before applying the keymap, so it
looks at the bindings' default keys. A binding whose default key is printable is gone even when
`bindings.overrides` moves it to a key the input doesn't consume. With `"app.maximize_widget": "f2"`, `f2` in the
search box does nothing and the footer has no `f2 Maximize`, while `f2` works everywhere else. The reverse also
happens: a binding with a non-printable default rebound to a printable key stays listed in the footer, though the box
types that key.

`/` is never removed, because Textual stores `Binding("/")` under the key name `slash` and `key_to_character("slash")`
is `None`. The footer with the box focused is `/ Search  ^p Command Pallete`.

This makes #156 ("maximize with the search box focused maximizes the input alone") unreachable in Python: `M` types an
M, and a rebound maximize is filtered out. If Chris prefers filtering by the effective keys, a rebound maximize in the
box would maximize the input alone, as #156 describes, and the footer would list rebound keys that work.

Found while designing #169 with Python-only probes (`/`, then `f2` with the override above, at 100x30 on `base`).
