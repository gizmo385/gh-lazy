# B62: The run Overview's fields run together in one paragraph

- Id: B62
- Status: answered
- Answer: Follow the recommendation. (Chris, 2026-10-26, in a Claude Code session; see #239 and #240)
- Python reference: `ui/widgets/workflow_run_details.py` `WorkflowRunOverviewTabPane.compose`
- Recommendation: One field per line, as the code means: `Run Number`, `Event`, `Branch`, `Status`, `Conclusion` (when set), `Attempt` (when set), `Created` and `Updated` each on its own line, and the same for `SHA`, `Triggered by` and `Actor`.
- Rows: `workflows.run-overview`, `workflows.overview-commit-info`

`compose` builds the metadata as a list of `**Run Number:** 42`-style strings and joins them with a single `\n` into
one `Markdown` source. In markdown a single newline is a soft break, so the whole list renders as one wrapped
paragraph: `Run Number: 42 Event: push Branch: main Status: completed Conclusion: failure Attempt: 2 Created:
2026-03-04 05:06:07 Updated: 2026-03-04 07:20:00`, wrapped wherever the width falls, often splitting a label from
its value. The commit block does the same with `SHA`, `Triggered by` and `Actor`. The `run-details` scenario's
`overview` capture shows both.

Found while designing the run Overview. Until Chris answers, the recommendation stands and the specs follow it; the
scenario's `[expect]` only checks text both layouts show.
