# B63: The Jobs tab shows `?` for a queued job

- Id: B63
- Status: open
- Python reference: `ui/widgets/workflow_run_details.py` `WorkflowRunJobsTabPane._format_job_status`, `_format_step_status`; `WorkflowRunOverviewTabPane._format_job_status`
- Recommendation: Use the Overview's icons in the Jobs tab too: a queued job, and a queued step, show a yellow `⋯`. Other statuses and conclusions keep their icons, and anything else stays a dim `?`.
- Rows: `workflows.jobs-tab`, `workflows.jobs-status-icons`

The Overview's job summary and the Jobs tab's tree each format a job's status with their own copy of
`_format_job_status`. The Overview's handles `queued` (a yellow `⋯`); the Jobs tab's doesn't, so the same queued job
is `⋯ test (Not started)` in the Overview and `? test (queued)` in the Jobs tab (the `run-details` scenario's
`in-progress` and `in-progress-jobs` captures). `_format_step_status` has the same gap for a queued step.

Found while designing the Jobs tab. Until Chris answers, the recommendation stands and the specs follow it.
