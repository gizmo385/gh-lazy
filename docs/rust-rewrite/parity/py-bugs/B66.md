# B66: An added reaction of a new kind doesn't show in the PR's reactions summary

- Id: B66
- Status: answered
- Answer: Follow the recommendation. (Chris, 2026-10-27, in a Claude Code session; see #175)
- Python reference: `models/github.py` `ReactionSet.add_reaction`; `ui/widgets/pull_requests.py` `PrOverviewTabPane.trigger_reactions_modal`
- Recommendation: After posting, show each reaction GitHub accepted in the summary: its kind with one more, and the current user listed under it, whether or not anyone had given that kind before.
- Rows: `pull-requests.overview-add-reaction`

After Add reaction, `trigger_reactions_modal` records each reaction GitHub accepted with `ReactionSet.add_reaction`
and redraws the summary from that set. `add_reaction` has its `if` / `elif` the wrong way round for this: when the
kind isn't in the set yet it adds an empty set of users for it and never adds the user, so its count is 0 and the
summary leaves it out. Adding a kind somebody else already gave works. Since the modal only lists kinds the current
user hasn't given, a reaction nobody had given before (😄 on PR 5 in the `pr-reactions` scenario) is posted but
doesn't appear until the PR is opened again.
