# B67: Trigger without a workflow picked crashes the app

- Id: B67
- Status: open
- Python reference: `ui/screens/trigger_workflow.py` `TriggerWorkflowModal.action_submit`
- Recommendation: Do what the code meant: toast error / "Validation Error" "You must select a workflow!" and keep the modal open.
- Rows: `modals.trigger-workflow`

`action_submit` checks `workflow_select.value == Select.BLANK`, but in Textual 8 an empty `Select` holds
`Select.NULL` and `Select.BLANK` is `False`, so the check never matches. The next line,
`assert isinstance(workflow_id, int)`, then fails and the app exits with an `AssertionError` traceback. Pressing
Trigger (or `shift+enter`) before picking a workflow therefore crashes LazyGithub, and the "You must select a
workflow!" toast is never shown.
