# B69: Edit issue's Save never shows "Saving..." or disables itself

- Id: B69
- Status: answered
- Answer: Follow the recommendation. (Chris, 2026-10-27, in a Claude Code session; see #175)
- Python reference: `ui/screens/edit_issue.py` `EditIssueContainer.handle_submit_button`
- Recommendation: Do what the code meant: while the update is in flight the button reads "Saving..." and is disabled, so a second press can't send a second update.
- Rows: `modals.edit-issue`

`handle_submit_button` is an `@on(Button.Pressed, "#save_updated_issue")` handler whose parameter is named
`save_button: Button`, but Textual passes the `Button.Pressed` message. Setting `label` and `disabled` on the message
changes nothing on screen: Save keeps its label, stays enabled, and pressing it again while the first update is in
flight sends another `PATCH`.
