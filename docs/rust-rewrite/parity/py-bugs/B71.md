# B71: A failed review submit says nothing

- Id: B71
- Status: answered
- Answer: Follow the recommendation. (Chris, 2026-10-27, in a Claude Code session; see #175)
- Python reference: `lib/github/pull_requests.py` `create_new_review`; `ui/widgets/split_diff_viewer.py` `SplitDiffViewer.on_trigger_review_submission`
- Recommendation: Toast error / "Error submitting review" "Could not submit the review", keep the pending comments and the form as they were, and log the error.
- Rows: `diff-viewer.submit-review`

`create_new_review` catches the request's failure, logs it as "Error loading PRs for current commit" (a copy of
another function's message) and returns `None`; `on_trigger_review_submission` then does nothing more. Pressing
Submit Review when GitHub refuses the review (a stale head sha, a comment on a line outside the diff, a review on
one's own PR with Approve) only re-enables the button: no toast, and the pending comments stay as if nothing happened.
