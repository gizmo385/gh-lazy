# B76: Enter in an empty Reviewers input looks up the user ""

- Id: B76
- Status: open
- Python reference: `ui/screens/create_or_edit_pull_request.py` `ReviewerSelectionContainer.handle_new_reviewer_submitted`, `_validate_new_reviewer`; `lib/github/users.py` `get_user_by_username`
- Recommendation: Ignore Enter when the trimmed text is empty: no request, no toast.
- Rows: `modals.pr-reviewers`

Enter in Create/Edit PR's Reviewers input submits `value.strip().lower()` without checking it's non-empty, so a blank
input requests `GET /users/`. Real GitHub answers that path with a list of users (200), which `User(**response.json())`
can't take, and the worker's exception crashes the app; a 404 there would instead toast "Could not find user  - are
you sure they exist?" with an empty name.
