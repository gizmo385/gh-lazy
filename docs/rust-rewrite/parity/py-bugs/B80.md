# B80: `R` on an empty Unread tab crashes the app

- Id: B80
- Status: answered
- Answer: Follow the recommendation. (Chris, 2026-10-28, on #293)
- Python reference: `ui/screens/notifications.py` `UnreadNotificationTabPane.action_mark_read`
- Recommendation: `R` with no highlighted row (an empty Unread tab, or a search that hides every row) does nothing.
- Rows: `modals.notifications-empty`, `keybindings.notifications-mark-read`

`action_mark_read` reads the ID cell at the cursor with `get_cell_at` without checking that a row exists. On an empty
Unread table (nothing unread, or right after `ctrl+r`) that raises `CellDoesNotExist`, and the app exits with a
traceback. Seen in the `notifications-mark-all` flow (`ctrl+r`, `u`, `R`) while speccing #189; the committed scenario
leaves the `R` out.
