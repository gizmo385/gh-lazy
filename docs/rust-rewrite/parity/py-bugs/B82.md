# B82: A failed mark-all-as-read crashes the app

- Id: B82
- Status: open
- Python reference: `lib/github/notifications.py` `mark_all_notifications_as_read`; `ui/screens/notifications.py` `NotificationsContainer.all_notifications_marked_as_read`
- Recommendation: When the `PUT` fails, log `Failed to mark all notifications as read` at error and show it as an error toast; both tabs stay as they were and the Unread tab stays active.
- Rows: `modals.notifications-errors`, `keybindings.notifications-mark-all-as-read`

`mark_all_notifications_as_read` calls `raise_for_status()` on the `PUT /notifications` response, and nothing above it
catches `GithubApiRequestFailed`, so any failure (a 500, a lost connection, a token without the `notifications` scope)
exits the app with a traceback from the message handler. Seen with a 500 fixture while speccing #189.
