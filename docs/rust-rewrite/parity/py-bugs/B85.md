# B85: Edit PR warns that the current directory's branch has no upstream

- Id: B85
- Status: open
- Python reference: `ui/screens/create_or_edit_pull_request.py` `on_mount`, `ensure_directory_branch_has_configured_upstream`
- Recommendation: run the upstream check only when the dialog creates a PR; Edit PR never shows the warning. Owner decision 2026-10-28 (#283).
- Rows: `modals.edit-pr`

`on_mount` calls `ensure_directory_branch_has_configured_upstream` whether or not `existing_pull_request` is set, so
Edit PR shows "Warning: Current local branch has no configured upstream" whenever the branch checked out in the
current directory has no upstream. That branch has nothing to do with the PR being edited, whose base and head are
fixed and shown disabled, so the warning is misleading.
