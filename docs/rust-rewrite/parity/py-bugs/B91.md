# B91: Saving Settings after a palette toggle hid a section leaves a blank gap

- Id: B91
- Status: answered
- Answer: Follow the recommendation. ([Chris, 2026-10-28](https://github.com/gizmo385/gh-lazy/issues/193#issuecomment-6485805292))
- Python reference: `ui/screens/primary.py` `handle_settings_update`, `SelectionsPane.update_displayed_sections`,
  `action_toggle_ui`
- Recommendation: After Save, each of the Pull Requests, Issues and Workflows sections is shown or hidden exactly as
  its `appearance.show_*` says, as if no toggle had touched it: a shown section is laid out, drawn and takes its focus
  key again.
- Rows: `modals.settings-apply`

A palette toggle that hides a section sets both its `display` and its `visible` to false; showing it sets both back.
Settings' Save only sets `display` from `appearance.show_*`. So after "Toggle Issues" hides Issues, any Save (with
Show Issues still on) gives Issues its space in the column back but leaves it invisible: a blank gap where the box
should be, and `3` still does nothing. Toggling again hides it, and toggling a third time finally shows it. Seen in
the Python app at 160x48 (toggle Issues off, open Settings, Save).
