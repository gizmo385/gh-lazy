# B92: A section that Settings shows isn't loaded

- Id: B92
- Status: answered
- Answer: Follow the recommendation. ([Chris, 2026-10-28](https://github.com/gizmo385/gh-lazy/issues/193#issuecomment-6485805292))
- Python reference: `ui/screens/primary.py` `handle_settings_update`, `SelectionsPane.update_displayed_sections`,
  `SelectionsPane.load_repository`, `action_toggle_ui`
- Recommendation: When Save shows a section that was hidden and a repo is selected, load it the way a palette toggle
  showing it does (Workflows: the runs cache, then the workflows and the first runs page; Issues or Pull Requests: the
  first issues page).
- Rows: `modals.settings-apply`

Selecting a repo loads only the sections that are displayed. A section hidden by `appearance.show_*` and then turned
on in Settings appears with an empty table, and stays empty until another repo is selected. The palette's toggle,
which shows the same section, reloads it (`command-palette.toggle-*`).
