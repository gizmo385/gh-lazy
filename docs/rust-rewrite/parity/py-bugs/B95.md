# B95: The Debug Info modal cuts the config off, with no way to scroll

- Id: B95
- Status: answered
- Answer: Follow the recommendation. (Chris, 2026-10-28, [comment](https://github.com/gizmo385/gh-lazy/issues/312#issuecomment-6485044235))
- Python reference: `ui/screens/debug.py` `DebugContainer`, `DebugModal` (CSS `max-height: 80%`); Textual 8.2.5
  `Container` (`overflow: hidden hidden`), `Markdown` (not focusable, not scrollable)
- Recommendation: Let the markdown scroll: the area above the buttons scrolls with the mouse wheel, and with the
  scroll keys of other scroll areas (the user profile's body) while it has focus, with a scrollbar when it
  overflows. It's a tab stop after the two buttons; focus still starts on Copy to Clipboard, so the opening screen and
  footer are Python's. The buttons stay where they are, and Copy to Clipboard keeps copying all of it.
- Rows: `modals.debug-modal-contents`

The modal is a `Container` capped at 80% of the screen, holding a `Markdown` widget, a `Rule` and the buttons docked
at the bottom. The config is about 60 lines, so at 160x48 the screen shows it down to `"overrides": {}` and then
the buttons; at 100x30 it shows only the opening `{`. The container clips (`overflow: hidden`), the `Markdown`
widget isn't focusable and can't scroll, and no binding moves it, so the rest of the config can't be read in the app
at any size (scenario `debug-info`, captures `open` at both sizes). The full text still reaches the clipboard through
Copy to Clipboard and the terminal through `lazy-github debug`.

Found while designing the Debug Info modal (#195, #312). #312's spec
follows the answer.
